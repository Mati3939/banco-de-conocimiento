01

Flujo de trabajo y preparación de datos

El punto de partida de todo el curso: qué pasos seguir antes de graficar y cómo dejar los datos listos para eso.

Flujo de trabajo

  • Preparar: cargar con pandas/polars, inspeccionar con df.info()/df.describe(), tipar columnas.
  • Estética: fijar estilo antes de graficar, ej. sns.set_style('darkgrid'), y una paleta consistente.
  • Graficar: elegir el tipo según la pregunta (relación, distribución, comparación, composición, geoespacial).
  • Personalizar: título, ejes, leyenda, anotaciones — sin esto un gráfico no comunica.

Ecosistema: matplotlib (motor base) · seaborn (estadístico de alto nivel) · plotly.express (interactivo) · altair (declarativo) · streamlit (dashboards web).

Preparación y limpieza de datos

  • Unificación: pl.concat([df_a, df_b], how="diagonal") (Polars) — rellena con nulos las columnas que faltan en uno de los dos.
  • Casting: pd.to_numeric(col, errors="coerce").fillna(0) antes de unir tipos incompatibles.
  • Normalización de texto: mapear variantes a un nombre canónico (ej. región del INE vs. GeoJSON) — imprescindible antes de un mapa.
  • Deduplicación: df.drop_duplicates() antes de sumar, para no inflar totales.
  • Formato largo: df.melt(id_vars=, value_vars=, var_name=, value_name=) — necesario para barras apiladas o parallel_categories.
  • Discretización: pd.cut(col, bins=[...], labels=[...]) (rangos fijos) vs. pd.qcut(col, q=3, labels=[...]) (cuantiles).

💡 Ejemplos resueltos

1. Unificar y normalizar datos antes de graficar (Polars)

import polars as pl

# limpiar.py: unifica votos de Chile y del extranjero
votos = pl.concat([votos_chile, votos_extranjero], how="diagonal")  # rellena con null lo que falte en uno

votos = votos.with_columns(pl.col("region").cast(pl.String))  # casting explícito antes de unir

def normalizar_nombre_region(nombre):
    mapeo = {"DE VALPARAISO": "Valparaíso", "METROPOLITANA DE SANTIAGO": "Metropolitana"}
    return mapeo.get(nombre.upper(), nombre)

votos = votos.with_columns(
    pl.col("region").map_elements(normalizar_nombre_region).alias("region_normalizada")
)

pl.concat(..., how="diagonal") une dos DataFrames aunque tengan columnas distintas, completando con nulos donde falte una columna en uno de los dos. El cast(pl.String) evita errores de tipo al unir. La normalización de nombres de región es el paso más silenciosamente crítico: un featureidkey de mapa que no encuentre "DE VALPARAISO" en el GeoJSON simplemente deja esa región sin color, sin lanzar ningún error.

Fuente: nota "Preparación y limpieza de datos para visualización" (script limpiar.py y función load_data de app.py).

02

Buenas prácticas y elección del gráfico

La pregunta define el gráfico, y la personalización define si ese gráfico comunica o no.

Buenas prácticas y personalización

  • Título y ejes: siempre en español y describiendo la pregunta, no el nombre crudo de la columna.
  • Escala log: plt.xscale('log')/yscale('log') con outliers extremos o varios órdenes de magnitud.
  • Rotación de etiquetas: xaxis_tickangle=-45 evita superposición con nombres largos.
  • Paleta con significado: color_discrete_map / alt.Scale(domain=, range=) en vez del color por defecto.
  • Anotaciones: fig.add_annotation(x=, y=, text=, showarrow=True) para destacar un punto puntual.
  • tight_layout() y grillas de subplots para comparar varias variables ordenadamente.

03

Gráficos de relación y distribución

¿Covarían dos variables numéricas? ¿Cómo se reparte una sola? Las dos preguntas más frecuentes al empezar a explorar un dataset.

Gráficos de relación

FunciónUso
sns.scatterplot(data,x,y,hue=)nube de puntos; hue = 3ª variable
sns.pairplot(df,hue=)matriz de scatters + histogramas/KDE en diagonal
sns.lmplot(...,col=,row=)scatter + regresión, con facetas
px.scatter(...,trendline="ols")scatter interactivo + tendencia OLS
px.scatter_3d(x,y,z,color=)dispersión en 3 dimensiones

Con miles de puntos superpuestos (overplotting) conviene alpha bajo o pasar a heatmap/hexbin. Correlación (tendencia) no implica causalidad.

Gráficos de distribución

  • sns.histplot(df[col], bins=30, kde=True) — histograma + densidad.
  • sns.kdeplot(data,x,hue,fill=True,common_norm=False) — comparar forma, no magnitud, entre grupos.
  • sns.boxplot(data,x,y,showmeans=True) — mediana, cuartiles, bigotes; bueno para muchos grupos.
  • sns.violinplot(data,x,y) — revela multimodalidad que el boxplot esconde.
  • px.histogram(...,marginal="box") / px.violin(...,box=True,points="outliers") — versión interactiva.

Error común: common_norm=True (default) hace que el grupo con más datos "domine" el área total.

📶 Histograma: cuántos bins revelan (u ocultan) la forma real

40 valores de ejemplo con dos "grupos" naturales (bimodal). Mové el slider de bins y mirá cuándo aparece — o desaparece — la segunda moda.

Con pocos bins, ambos grupos se funden en una sola "montaña".

Leé el gráfico: con muy pocos bins (3-4) el histograma esconde la bimodalidad; con muchos (20+) aparece ruido de muestreo. El punto intermedio (≈8-10 acá) muestra la estructura real — sns.histplot(..., bins=N, kde=True) ayuda a decidir con la curva de densidad superpuesta.

import plotly.express as px

fig = px.scatter(

trendline="ols" ajusta una línea de mínimos cuadrados ordinarios sobre el scatter, útil para ver si la relación es aproximadamente lineal y si el retorno marginal del ingreso sobre la felicidad es decreciente. 04

Comparación, correlación y multivariados

Comparar categorías, leer una matriz de correlación y ver muchas variables relacionadas a la vez.

Gráficos de comparación categórica

  • sns.barplot(data,x,y) — media por categoría + IC.
  • plt.pie(...) — solo para pocas categorías (≤5-6).
  • px.bar(...,error_y=,text_auto=) — barras con incertidumbre.
  • Barras apiladas: groupby([...]).size().unstack().plot(kind="bar",stacked=True) o px.bar(...,color="Factor") con datos melt.
  • px.line_polar(r=,theta=,color=,line_close=True) — perfil multivariable entre grupos.

Heatmaps y matrices de correlación

  • df.corr() — matriz de correlación de Pearson (-1 a 1); ignora columnas no numéricas en silencio.
  • px.imshow(corr, text_auto=True, color_continuous_scale="RdBu_r") — paleta divergente porque 0 es el punto neutro.
  • Clustering jerárquico: scipy.cluster.hierarchy.linkage (average, euclidean) sobre datos con StandardScaler + create_dendrogram — reordena filas/columnas por similitud.

Correlación mide relación lineal; dos variables no lineales pueden dar ≈0 y estar fuertemente relacionadas igual.

Gráficos multivariados avanzados

  • Facetas / small multiples: lmplot(...,col=,row=), px.histogram(...,facet_col=).
  • px.parallel_categories(dimensions=[...],color=) — cada observación es una línea que atraviesa columnas categóricas; requiere discretizar antes con qcut.
  • px.scatter_3d(x,y,z,color=) — tres ejes numéricos + color como 4ª dimensión.
  • Marginal histograms: px.scatter(...,marginal_x="histogram",marginal_y="histogram").

Error común: más de 4-5 dimensiones en parallel_categories se vuelve "spaghetti" ilegible.

🌡️ Correlación interactiva: scatter y heatmap a la vez

Mové el slider de correlación entre dos variables: la nube de puntos se estira/comprime y la celda correspondiente de la mini matriz de correlación cambia de color y valor.

correlación positiva correlación negativa

Leé el gráfico: izquierda, sns.scatterplot de X vs. Y con la correlación elegida; derecha, la matriz df.corr() de 2×2 con px.imshow(color_continuous_scale="RdBu_r") — la diagonal es siempre 1 (gris fuerte), la celda fuera de diagonal responde al slider.

5. Matriz de correlación y heatmap clusterizado

import numpy as np
from sklearn.preprocessing import StandardScaler
from scipy.cluster.hierarchy import linkage
import plotly.figure_factory as ff
import plotly.express as px

corr = df.select_dtypes(include=[np.number]).corr()
fig = px.imshow(corr, text_auto=True, color_continuous_scale="RdBu_r")

datos_norm = StandardScaler().fit_transform(df_paises[factores])
enlace = linkage(datos_norm, method="average", metric="euclidean")
dendro = ff.create_dendrogram(datos_norm, linkagefun=lambda x: enlace, labels=paises)

select_dtypes(include=[np.number]) evita que df.corr() ignore silenciosamente columnas de texto. RdBu_r es una paleta divergente adecuada porque la correlación tiene un punto neutro natural (0). El clustering jerárquico agrupa países con perfiles de bienestar parecidos antes de dibujar el heatmap final, revelando "familias" no obvias en la tabla cruda (ej. Costa Rica cerca de Nueva Zelanda) — normalizar con StandardScaler es obligatorio o la variable de mayor escala domina la distancia euclidiana.

for col in ["Economy (GDP per Capita)", "Health", "Freedom", "Trust"]:

05

Mapas y tablas dinámicas

Cuando el dato tiene ubicación geográfica, o hay que cruzarlo por dos dimensiones categóricas a la vez.

Mapas coropléticos y geoespaciales

  • GeoJSON: geometrías de regiones/comunas + propiedades (nombre, código).
  • px.choropleth_mapbox(df, geojson=, locations=, featureidkey="properties.REGION", color=, mapbox_style="carto-positron") — mapa nacional/regional sobre mapa base real.
  • px.choropleth(locations=, locationmode="country names", color=, projection="natural earth") — mapa mundial sin GeoJSON propio.

Trampa silenciosa: si locations no calza exacto con el GeoJSON, la región queda gris sin error — hay que normalizar texto (mayúsculas, tildes, prefijos) antes.

Tablas dinámicas

pivot = df.pivot_table(
    index=["candidato"], columns=["region"],
    values="votos", aggfunc="sum", fill_value=0
)

index/columns = qué va en filas/columnas; aggfunc = función de resumen; fill_value=0 evita NaN en combinaciones sin datos. En Streamlit: st.multiselect elige filas/columnas dinámicamente y st.download_button exporta a CSV.

6. Construí una tabla dinámica de ventas totales por vendedor (filas) y mes (columnas), sin que aparezcan NaN en combinaciones sin ventas. media 
pivot = df.pivot_table(
    index="vendedor", columns="mes", values="monto",

fill_value=0 es la parte que evita el problema: sin ella, cada combinación vendedor-mes sin ventas queda como NaN, lo que rompe sumas totales por fila/columna y puede fallar al exportar a CSV. Con fill_value=0 esas combinaciones quedan en cero, un valor numéricamente correcto ("no vendió ese mes").

7. Un mapa coroplético de regiones de Chile sale con la mitad de las regiones en gris (sin dato), aunque el CSV tiene datos para las 16 regiones. Diagnosticá y corregí. dificil 
# diagnóstico: comparar los nombres que usa el CSV contra los del GeoJSON
nombres_csv = set(df["region"].unique())
nombres_geojson = {f["properties"]["REGION"] for f in chile_geojson["features"]}
print(nombres_csv - nombres_geojson)   # regiones del CSV que NO calzan

# corrección: normalizar antes de graficar
mapeo = {"DE VALPARAISO": "Valparaíso", "METROPOLITANA DE SANTIAGO": "Metropolitana", ...}
df["region_normalizada"] = df["region"].str.upper().map(mapeo).fillna(df["region"])

)

El síntoma (regiones grises sin error) es la firma exacta del problema de featureidkey: locations no calza carácter por carácter con la propiedad del GeoJSON (mayúsculas, tildes, prefijos "DE"). El diagnóstico compara ambos conjuntos de nombres con una diferencia de sets; la corrección aplica el mismo diccionario de normalización usado en la preparación de datos (ejemplo 1) antes de graficar.

Dashboards: Streamlit y Altair

De un notebook a una app web interactiva: widgets, cache y una gramática declarativa de gráficos.

Dashboards con Streamlit

  • st.set_page_config(page_title=,layout="wide"), st.file_uploader + @st.cache_data (evita releer en cada interacción).
  • Widgets: st.sidebar.selectbox, st.multiselect, st.radio — filtran el DataFrame antes de graficar.
  • Layout: st.columns(n), st.tabs([...]), st.metric(label,valor).

07

Storytelling con datos: contexto, atención y narrativa

Las seis lecciones de Cole Nussbaumer Knaflic ("Storytelling with Data"): el complemento de diseño a todo lo aprendido con las librerías — un gráfico técnicamente correcto todavía puede no comunicar nada.

Entender el contexto y la audiencia

Antes de abrir matplotlib/plotly, la primera lección de Knaflic es responder tres preguntas: ¿quién es la audiencia (un directorio, la prensa, el propio equipo de análisis)?, ¿qué necesita saber?, y sobre todo ¿qué necesita hacer con esa información? Un gráfico sin una acción o decisión asociada rara vez justifica su lugar en un informe.

  • La "gran idea" (big idea): una sola frase que resuma el mensaje central del gráfico, escrita antes de graficar — no un título genérico como "Ventas por región" sino "La región Centro concentra el 60% de las ventas".
  • Mismo dato, presentación distinta según la audiencia: un mapa coroplético interactivo (px.choropleth_mapbox) sirve para exploración libre en prensa; una tabla dinámica exportable (pivot_table + st.download_button) sirve para que el equipo de campaña la procese en Excel.
  • Menos es más: si la audiencia tiene 10 segundos, un st.metric con una cifra y una flecha de tendencia comunica más rápido que un dashboard completo.

Atributos preatentivos: dirigir la mirada antes de que piense

Los atributos preatentivos son propiedades visuales que el cerebro procesa de forma automática, en fracciones de segundo y antes del razonamiento consciente: color, tamaño, posición y orientación/negrita. Usarlos con intención es la diferencia entre "acá están todos los datos" y "mirá esto".

  • Color de énfasis: pintar gris ("#95a5a6") todas las categorías salvo la relevante, que queda con el único color saturado del gráfico — el ojo la encuentra sin leer ninguna etiqueta.
  • Tamaño / grosor: una línea o barra más gruesa que el resto comunica jerarquía sin necesitar texto.
  • Posición: ordenar barras de mayor a menor (en vez de alfabético) hace que el ranking se lea de un vistazo.
  • Negrita selectiva en texto: resaltar solo el número que importa dentro de un párrafo cumple la misma función que el color en un gráfico.

Trampa común: usar 6-7 colores saturados distintos (uno por categoría) es lo opuesto a esto — sin ningún color "por defecto" que actúe de fondo, el ojo no tiene dónde aterrizar primero.

Eliminar el desorden: data-ink ratio y chartjunk

El concepto de data-ink ratio (Edward Tufte, retomado por Knaflic como lección 3) formaliza una idea que ya apareció en la animación de la Unidad 2: cada elemento visual que no representa un dato es candidato a borrarse.

Data-ink ratio (Tufte)$$\text{ratio}=\frac{\text{tinta usada en datos}}{\text{tinta total del gráfico}},\qquad 0\le\text{ratio}\le1$$

Cuanto más cerca de 1, menos "ruido" compite con la información real. Categorías típicas de chartjunk (tinta que no es dato) a eliminar por defecto:

  • Grillas de fondo pesadas — ax.grid(alpha=0.15) o directamente quitarlas, nunca al 100% de opacidad.
  • Bordes/marcos gruesos y efectos 3D en barras o tortas (plt.pie(..., shadow=True) es casi siempre chartjunk puro).
  • Leyendas redundantes cuando se puede etiquetar la serie directamente sobre la línea (fig.add_annotation al final de cada línea en vez de una leyenda aparte).
  • ax.spines['top'].set_visible(False) / ['right'].set_visible(False) — los ejes superior y derecho casi nunca aportan información.

Pensar como diseñador

  • Affordances: que un elemento interactivo se vea interactivo — un st.selectbox con placeholder claro, un botón con verbo de acción ("Descargar CSV", no "OK").
  • Accesibilidad: paletas seguras para daltonismo (evitar rojo-verde puro; RdBu/viridis funcionan mejor que rojo/verde saturado), tamaño de fuente legible incluso proyectado, texto alternativo en gráficos exportados.
  • Iterar: la primera versión de un gráfico casi nunca es la que se presenta — mostrarla a alguien que no conoce el dato y ver qué pregunta primero revela qué falta aclarar.

Contar una historia con datos

La última lección de Knaflic: estructurar el análisis igual que una historia, con contexto → tensión (el hallazgo que sorprende o importa) → resolución (qué hacer al respecto), en vez de una sucesión plana de gráficos.

  • Lógica horizontal: cada panel/slide comunica UNA idea propia — si hace falta explicarlo con dos oraciones distintas, son dos gráficos, no uno.
  • Lógica vertical: el título de un gráfico debería ser la conclusión ("La participación cayó 8 puntos en la región Sur"), no una descripción del eje ("Participación por región").
  • Aplicado al dashboard electoral: en vez de mostrar el mapa de Chile solo, ordenar la narrativa como st.metric con la cifra clave (contexto) → mapa coroplético con la región líder anotada (tensión/hallazgo) → tabla dinámica exportable para profundizar (resolución/acción).

👁️ Atención preatentiva: mismo gráfico, dos formas de mirarlo

Las mismas 7 barras, sin ningún cambio de datos: "Sin atención dirigida" las pinta todas con el mismo color saturado; "Con atención dirigida" apaga el resto a gris y deja un único color + etiqueta en la barra que importa.

Sin atención dirigida: 7 colores saturados compitiendo — el ojo no sabe dónde mirar primero.

Leé el gráfico: en el segundo estado, ningún dato cambió — solo el color. La región Centro (la del hallazgo) se identifica sin leer ninguna etiqueta, exactamente el efecto que busca un atributo preatentivo bien usado.

9. Resaltar una sola categoría con color preatentivo

import plotly.express as px

GRIS = "#95a5a6"
region_destacada = "Centro"

colores = {r: (GRIS if r != region_destacada else "#c0392b") for r in df["region"].unique()}

fig = px.bar(
    df, x="region", y="votos",
    color="region", color_discrete_map=colores,
    title="La región Centro concentró el 60% de los votos"   # la "big idea", no una descripción del eje
)
fig.update_layout(showlegend=False)   # el color ya comunica; la leyenda es chartjunk acá

El diccionario colores asigna gris a TODAS las regiones salvo la destacada, que recibe el único color saturado del gráfico — el mismo truco de "todo gris salvo uno" funciona igual en matplotlib (ax.bar(..., color=[GRIS if r != destacada else "#c0392b" for r in regiones])). El título ya es la "gran idea" (Lección 1), no una descripción genérica, y la leyenda se quita porque el color ya es autoexplicativo con el título puesto.
