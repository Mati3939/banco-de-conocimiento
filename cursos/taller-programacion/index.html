01

Pseudocódigo y lógica de programas

El lenguaje previo a cualquier código: diagramas de flujo, selección y repetición antes de escribir la primera línea de Python.

Pseudocódigo y diagramas de flujo

  • Selección simple: Si (condición) entonces ... Fin_si. Compuesta: agrega De lo contrario ... Fin_si.
  • Mientras haga: evalúa la condición antes de entrar (0 o más iteraciones).
  • Haga mientras: evalúa la condición después de ejecutar (1 o más iteraciones garantizadas).
  • Para: usa una variable iteradora que va de Vi a Vf, indicando si INCrementa o DECrementa.
  • Diagrama de flujo: óvalo = inicio/fin, rombo = decisión, rectángulo = proceso, paralelogramo = entrada/salida.
  • Sin modificador de condición dentro de un Mientras → ciclo infinito.

💡 Ejemplos resueltos

1. De pseudocódigo a Python: contar pares e impares

Pseudocódigo original (nota de Pseudocódigo y diagramas de flujo), estructura Mientras Haga:

cantimp <- 0 ; cantpar <- 0 ; X <- 0
Mientras (X<N) haga
    Leer (Num)
    Si (Num MOD 2 <> 0) entonces
        cantimp <- cantimp + 1
    De lo contrario
        cantpar <- cantpar + 1
    Fin_Si
    X <- X + 1
Fin_Mientras

Traducción a Python (con una lista de números en vez de leer del teclado):

numeros = [4, 7, 10, 3, 8]
cantpar = 0
cantimp = 0
x = 0
while x < len(numeros):
    num = numeros[x]
    if num % 2 == 0:
        cantpar += 1
    else:
        cantimp += 1
    x += 1
print(cantpar, cantimp)

Cada palabra reservada del pseudocódigo tiene su equivalente: Mientras...haga/Fin_Mientras → while: (indentación en vez de Fin_), Si/De lo contrario/Fin_Si → if/else:, <- → =, MOD → %. Con la lista [4, 7, 10, 3, 8] el resultado es 3 pares, 2 impares — puedes seguir el mismo trazado en el visualizador de la próxima unidad.

Fuente: nota "Pseudocódigo y diagramas de flujo".

✏️ Ejercicios

1. Traduce a Python: Mientras (cont <= 10) haga / Escribir(cont) / cont <- cont + 2 / Fin_Mientras, con cont iniciando en 0. fácil 
cont = 0
while cont <= 10:
    print(cont)

<- se traduce como =, Escribir(...) como print(...), y el bloque queda delimitado por indentación en vez de Fin_Mientras. Imprime 0, 2, 4, 6, 8, 10 — al llegar a cont=12 la condición 12 <= 10 es falsa y el ciclo termina.

02

Variables, tipos de datos y estructuras de control

Qué guarda una variable, cómo se castea entre tipos, y las tres formas de controlar el flujo de un programa: si, mientras y para.

Variables y tipos de datos

  • Tipos básicos: int, float, str, bool. Estructurados: lista, tupla, diccionario, set.
  • Todo dato en Python es un objeto con identidad (id(x)), tipo (type(x)) y valor.
  • Operadores aritméticos: + - * / // % ** · comparación: == != < > <= >= · lógicos: and, or, not.
  • Casting: int("3"), str(5), float("2.5"). Python no "declara" tipos: reasignar cambia el tipo dinámicamente.
  • / siempre entrega float; // es división entera; % es el resto.

Estructuras de control

if condicion:
    ...
elif otra:
    ...
else:
    ...

while condicion:      # nº de iteraciones desconocido
    ...

for i in range(n):    # nº de iteraciones conocido
    ...
  • break corta el bucle; continue salta a la siguiente iteración.
  • Python usa indentación para delimitar bloques (no Fin_si/Fin_mientras como el pseudocódigo).
  • Preferir for elemento in lista: sobre for i in range(len(lista)): cuando no se necesita el índice.

🔁 Trazador de un ciclo while: contar pares e impares

Cada clic en "Paso" ejecuta una línea del código, igual que el intérprete de Python.

03

Listas

La estructura de datos más usada del curso: ordenada, mutable, con un método para cada operación.

Listas

  • Ordenada, mutable, con corchetes []. Índice desde 0; L[-1] = último elemento. Índice fuera de rango → IndexError.
  • L[2:5] = sublista [inicio:fin), no incluye el fin. elemento in L comprueba pertenencia.
Método / funciónQué hace
.append(x)agrega x al final
.insert(i, x)inserta x en la posición i, corre el resto a la derecha
.pop(i)elimina y retorna el elemento en i (por defecto el último)
.remove(x)elimina la primera aparición del valor x
.index(x)retorna la posición de la primera aparición de x
.sort() / .reverse()ordena / invierte la lista en el lugar
.extend(L2)agrega todos los elementos de L2 al final
len(), sum(), max(), min()funciones globales sobre la lista

📋 Operaciones de lista: append / insert / pop / slice / index

Seis operaciones encadenadas sobre la misma lista, una por clic en "Paso".

L = [11, 3, 5, 7, 2]. Presioná Paso para ejecutar la primera operación.

Leé el gráfico: se ejecuta, en orden, L.append(100) → L.insert(2, 99) → L.pop() → L.pop(0) → L[1:3] → L.index(7), sobre la lista de la nota de Listas. Verde = elemento agregado, morado = insertado o encontrado, celeste = rango de un slice (no modifica la lista).

💡 Ejemplos resueltos

3. Procesar una lista: máximo y promedio

L = [11, 3, 5, 7, 2]

maxi = L[0]
for elem in L:
    if elem > maxi:
        maxi = elem

suma = 0.0
for elem in L:
    suma += elem
prom = suma / len(L)

print("Máximo:", maxi)     # 11
print("Promedio:", prom)   # 5.6

Máximo: se parte suponiendo que el primer elemento (L[0]=11) es el mayor, y se compara contra cada elemento; como ninguno supera a 11, maxi se queda en 11.

Promedio: patrón acumulador — suma arranca en 0.0 (float, para que la división no trunque) y se le suma cada elemento; al final se divide por len(L). (11+3+5+7+2)/5 = 28/5 = 5.6.

Fuente: nota "Listas".

✏️ Ejercicios

L.insert(2, 10)
print("Tras insert(2, 10):", L)      # [5, 3, 10, 8, 1, 9]

L.pop()

04

Diccionarios, tuplas y sets

Tres formas de agrupar datos que no son una lista: por llave, inmutable, o sin duplicados.

Diccionarios

  • {llave: valor, ...}; las llaves son únicas. Se accede por llave, no por posición.
  • Se pueden anidar (diccionario de diccionarios) y el valor puede ser de cualquier tipo (lista, tupla, etc.).
MétodoQué hace
d[llave]accede; si no existe → KeyError
.get(llave)accede; si no existe → None (sin error)
.items()pares (llave, valor), ideal para for k, v in d.items():
.keys() / .values()solo llaves / solo valores
.pop(llave)elimina la llave y retorna su valor
.clear()vacía el diccionario completo

Tuplas y sets

  • Tupla (a, b, c): ordenada como una lista, pero inmutable.
  • Set {a, b, c}: no ordenado, no indexado, elementos únicos; mutable, pero no puede contener listas.
  • {} vacío crea un diccionario, no un set vacío (usar set()).
A = {1, 2, 3}
B = {2, 3, 4}
A | B    # unión           -> {1, 2, 3, 4}
A & B    # intersección    -> {2, 3}
A - B    # diferencia      -> {1}
A ^ B    # dif. simétrica  -> {1, 4}

6. Con inventario = {"lápices": 120, "cuadernos": 45, "borradores": 6, "reglas": 30}, calcula el total de unidades y el producto con menor stock. media 
inventario = {"lápices": 120, "cuadernos": 45, "borradores": 6, "reglas": 30}

total = 0
for cantidad in inventario.values():
    total += cantidad
print("Total de unidades:", total)     # 201

producto_critico = min(inventario, key=inventario.get)
print("Menor stock:", producto_critico, "con", inventario[producto_critico])  # borradores con 6

.values() recorre solo los valores para sumarlos: 120+45+6+30=201. min(inventario, key=inventario.get) recorre las llaves del diccionario y usa inventario.get como criterio de comparación, entregando la llave (no el valor) con el menor stock: "borradores".

7. Con estudiantes = {1: ("Ana", {"Cálculo","Programación","Física"}), 2: ("Beto", {"Programación","Química"})}, obtén los ramos en común y los que solo tiene uno de los dos. difícil 
estudiantes = {
    1: ("Ana", {"Cálculo", "Programación", "Física"}),
    2: ("Beto", {"Programación", "Química"})
}

nombre1, ramos1 = estudiantes[1]
nombre2, ramos2 = estudiantes[2]

comunes = ramos1 & ramos2                 # {'Programación'}
solo_uno = ramos1 ^ ramos2                # {'Cálculo', 'Física', 'Química'}

print(f"En común: {comunes}")
print(f"Solo uno de los dos: {solo_uno}")

& es la intersección (ramos que están en ambos sets). ^ es la diferencia simétrica: los elementos que están en uno de los sets pero no en el otro — todo lo que no es común.

Strings y estructuras de datos

Texto como secuencia indexada, y una tabla que resume las cinco estructuras del curso lado a lado.

Strings

  • Inmutable; admite indexado s[0], slicing s[2:5] y len(s) igual que una lista.
  • .split() → string a lista; .join() → lista a string (proceso inverso).
  • f-strings (f"...") insertan variables directamente en el texto: f"Hola {nombre}!" — se usan en la mayoría de los ejemplos del curso para formatear salidas legibles.
MétodoQué hace
.strip(p) / .lstrip(p) / .rstrip(p)borra el patrón p al inicio y fin / solo inicio / solo fin
.replace(a, b)reemplaza todas las apariciones de a por b
.split(sep)separa por sep y retorna una lista
'-'.join(lista)une los elementos de la lista con '-'
.isdigit()True si el string son solo dígitos
.lower() / .upper()convierte a minúsculas / mayúsculas

8. Cuenta cuántas veces aparece cada palabra en "el perro corre y el gato corre", ignorando mayúsculas. media 
frase = "el perro corre y el gato corre"
palabras = frase.split()

frecuencia = {}
for palabra in palabras:
    palabra = palabra.lower()

06

Funciones

Parámetros, *args y el scope local: cómo dividir un problema en piezas reutilizables — y cómo Python las apila para ejecutarlas.

Funciones

def nombre(parametro1, parametro2=valor_defecto, *args):
    ...
    return resultado
  • Orden obligatorio al definir: posicionales → con valor por defecto → *args → **kwargs.
  • Variables dentro de la función son locales (scope): no existen fuera.
  • Sin return, la función entrega None.
  • Principios: DRY (no repetir código) y modularidad (dividir el problema en funciones pequeñas).

📚 Pila de llamadas a función

Traza la pila de llamadas de promedio_cuadrados(a, b), que a su vez llama a suma_cuadrados y dos veces a cuadrado.

Pila vacía.

Leé el gráfico: cada "Paso" empuja (push) un nuevo frame al llamar una función, o lo saca (pop) al hacer return. Aplica los conceptos de parámetros, return y modularidad de la nota de Funciones.

Recursión

  • Una función recursiva se llama a sí misma. Necesita un caso base (no vuelve a llamarse, corta la recursión) y un caso recursivo (se acerca al caso base en cada llamada).
  • Sin caso base (o si nunca se alcanza) → recursión infinita → RecursionError: maximum recursion depth exceeded.
  • Cada llamada agrega un nuevo frame a la pila de llamadas — la misma pila de la animación de arriba — hasta llegar al caso base; luego los return se resuelven "de atrás hacia adelante".
def potencia(base, exponente):
    if exponente == 0:            # caso base
        return 1
    return base * potencia(base, exponente - 1)   # caso recursivo

print(potencia(2, 3))    # 8

💡 Ejemplos resueltos

5. Funciones con valores por defecto y *args

def crear_perfil(nombre, edad=18, ciudad="Ciudad no especificada"):
    return f"{nombre}, {edad} años, vive en {ciudad}"

print(crear_perfil("Ana"))                  # Ana, 18 años, vive en Ciudad no especificada
print(crear_perfil("María", 25, "Madrid"))  # María, 25 años, vive en Madrid

def sumar(*numeros):
    total = 0
    for num in numeros:
        total += num
    return total

print(sumar(1, 2, 3))        # 6
print(sumar(1, 2, 3, 4, 5))  # 15

crear_perfil("Ana") solo pasa el parámetro obligatorio nombre; edad y ciudad toman sus valores por defecto. Al llamar con los tres argumentos, se sobrescriben en orden posicional.

*numeros empaqueta cualquier cantidad de argumentos en una tupla dentro de la función; el for los recorre y acumula la suma sin importar cuántos se pasaron.

Fuente: nota "Funciones".

6. Recursión: calcular una potencia sin usar **

def potencia(base, exponente):
    if exponente == 0:                  # caso base: exponente llegó a 0
        return 1
    return base * potencia(base, exponente - 1)

print(potencia(2, 3))    # 8
print(potencia(5, 0))    # 1  (caso base directo)

potencia(2, 3) no calcula nada de inmediato: llama a potencia(2, 2), que llama a potencia(2, 1), que llama a potencia(2, 0) — ahí el caso base devuelve 1 sin más llamadas. Desde ahí las multiplicaciones pendientes se resuelven "hacia atrás": 2*1=2, 2*2=4, 2*4=8. Cada llamada pendiente ocupa un frame en la pila (igual que en la animación de arriba) hasta que el caso base la libera.

Fuente: Calendarización oficial del curso — Unidad 5 "Funciones en Python", actividad "función recursiva para calcular potencias".

✏️ Ejercicios

9. Escribe una función mayor(*numeros) que retorne el mayor valor recibido, sin usar max(). media 
def mayor(*numeros):
    mas_grande = numeros[0]
    for num in numeros:
        if num > mas_grande:
            mas_grande = num
    return mas_grande

print(mayor(4, 17, 2, 9))    # 17
print(mayor(-3, -1, -8))     # -1

*numeros empaqueta los argumentos en una tupla. Se inicializa mas_grande con el primer elemento y se recorre comparando — el mismo patrón que "encontrar el máximo" de una lista, aplicado a un número variable de argumentos.

10. Escribe una función recursiva factorial(n) que calcule n! (para n ≥ 0), sabiendo que 0! = 1. media 
def factorial(n):
    if n == 0:                    # caso base
        return 1
    return n * factorial(n - 1)   # caso recursivo

print(factorial(5))    # 120
print(factorial(0))    # 1

factorial(5) se descompone en 5 * factorial(4), y así hasta factorial(0), que devuelve 1 directamente por el caso base. Desde ahí se resuelve hacia atrás: 1*1=1, 2*1=2, 3*2=6, 4*6=24, 5*24=120.

07

Módulos y manejo de archivos

De un archivo .py reutilizable a leer y escribir datos en disco, con los pasos de Pólya como guía para resolver problemas.

Módulos y librerías

import os                          # os.listdir(...)
from datetime import datetime      # datetime.now()
from collections import Counter    # Counter(lista)
  • Un módulo es un archivo .py con funciones/clases/variables reutilizables; una librería agrupa varios módulos.
  • Librería estándar útil: math, random, os, datetime, collections, csv, re.
  • No nombrar un archivo propio igual que un módulo oficial (p. ej. random.py) — se importaría el archivo propio en su lugar.

Manejo de archivos

with open("datos.txt", "r") as f:
    for linea in f:
        ...

with open("salida.csv", "w") as f:
    f.write("col1,col2\n")
  • Modos: "r" leer, "w" escribir (borra lo existente), "a" agregar al final.
  • with cierra el archivo automáticamente; sin él hay que llamar .close().
  • .rstrip('\n') es clave al leer líneas: quita el salto de línea antes de convertir con int()/float().
  • Pasos de Pólya para resolver: 1) entender el problema 2) crear un plan 3) llevarlo a cabo 4) revisar el resultado.

💡 Ejemplos resueltos

7. Módulo propio: matematicas.py

# matematicas.py
def sumar(a, b):
    return a + b

PI = 3.14159

class Calculadora:
    def __init__(self):
        self.historial = []

    def calcular(self, operacion, a, b):
        if operacion == "+":
            resultado = sumar(a, b)
        self.historial.append(f"{a} {operacion} {b} = {resultado}")
        return resultado

# otro_archivo.py
import matematicas

c = matematicas.Calculadora()
print(c.calcular("+", 2, 3))     # 5
print(matematicas.PI)             # 3.14159

matematicas.py agrupa una función (sumar), una variable (PI) y una clase (Calculadora) en un único módulo reutilizable. Desde otro_archivo.py, import matematicas trae todo el módulo, y se accede a cada elemento con el prefijo matematicas. — evita repetir el código en cada script que lo necesite.

Fuente: nota "Módulos y librerías" (matematicas.py).

8. Manejo de archivos: Radios_planetas.txt → Areas_planetas.csv

# 1. Leer el archivo y descubrir el separador de sus columnas
with open('Radios_planetas.txt', 'r') as datos:
    for linea in datos:
        print(linea)

# 2. Extraer y procesar la información dentro del ciclo
with open('Radios_planetas.txt', 'r') as datos:
    arreglo_info = []
    for linea in datos:
        info = linea.split(' ')[0:2]
        nombre = info[0]
        radio = float(info[1].rstrip('\n'))
        area = 4 * 3.14159 * radio ** 2
        arreglo_info.append((nombre, area))

# 3. Guardar el resultado en un archivo nuevo
with open('Areas_planetas.csv', 'w') as archivo_nuevo:
    archivo_nuevo.write('planeta,area\n')
    for nombre, area in arreglo_info:
        archivo_nuevo.write(f'{nombre},{area}\n')

Paso 1 (exploración): antes de procesar, se imprime cada línea cruda para descubrir cómo están separadas las columnas — en este caso por un espacio.

Paso 2: linea.split(' ')[0:2] separa la línea por espacios y se queda con las dos primeras columnas (nombre y radio). info[1].rstrip('\n') es imprescindible: sin quitar el salto de línea, float() fallaría o arrastraría un carácter inválido. El área de una esfera A = 4·π·r² se calcula con radio ** 2, y el resultado se guarda como tupla (nombre, area) dentro de una lista.

Paso 3: se abre un archivo nuevo en modo "w" (crea o sobrescribe) y se escribe una fila de encabezado más una fila por planeta, con formato CSV separado por comas mediante un f-string.

Manejo de excepciones y Programación Orientada a Objetos

Cómo capturar errores sin que el programa se caiga, y luego clases, objetos, herencia y sobre-escritura: el último paso del curso, con el ejemplo real de Agente/AgenteEspecial.

Manejo de excepciones (try/except/finally)

  • try: intenta ejecutar código que puede fallar; si ocurre un error del tipo indicado en except, el programa salta a ese bloque en vez de detenerse (traceback).
  • Se pueden encadenar varios except para distintos tipos de error, o usar except Exception as e: como comodín (atrapa cualquier error, pero conviene ser específico primero).
  • else: corre solo si no hubo excepción; finally: corre siempre (haya o no error) — típico para cerrar un archivo o liberar un recurso.
  • Errores comunes: ValueError (conversión inválida, p. ej. int("abc")), ZeroDivisionError (división por cero), KeyError (llave inexistente en un diccionario), IndexError (índice fuera de rango de una lista).
try:
    n = int(input("Ingrese un número entero: "))
    resultado = 10 / n
except ValueError:
    print("Eso no es un número entero.")
except ZeroDivisionError:
    print("No se puede dividir por cero.")
else:
    print("Resultado:", resultado)
finally:
    print("Fin del intento.")

Programación Orientada a Objetos

  • Los 4 pilares: encapsulamiento (ocultar el estado interno, acceder vía métodos), herencia (una clase hija reutiliza/extiende a una padre), polimorfismo (un mismo método —como reporte() en el ejemplo de abajo— se comporta distinto según la clase que lo ejecuta) y abstracción (exponer lo esencial, esconder el detalle de implementación).
  • Clase = plantilla; objeto = instancia; atributo = dato; método = función del objeto (siempre recibe self).
  • Atributo de clase (compartido por todas las instancias) vs. atributo de instancia (propio de cada objeto, se define con self. en __init__).
  • Herencia: class Hija(Padre): reutiliza/extiende. Llamar Padre.__init__(self, ...) para no perder la inicialización heredada.
  • Override: redefinir un método del padre en la hija (misma firma, comportamiento distinto) — la forma más simple de polimorfismo en este curso.
  • Dunder methods: __init__ (constructor), __str__ (texto con print(objeto)), __len__, __del__.
  • Un guion bajo inicial (_metodo) es convención de "privado"; Python no lo impide técnicamente.

9. Manejo de excepciones: pedir un número válido con reintento

def pedir_entero(mensaje):
    while True:
        try:
            return int(input(mensaje))
        except ValueError:
            print("Entrada inválida, intenta de nuevo.")

edad = pedir_entero("Ingrese su edad: ")
print(f"Tu edad es {edad}")

while True + try/except arma un bucle de reintento: si int(input(...)) falla (el usuario escribió texto no numérico), Python lanza ValueError, el except lo atrapa, imprime el aviso y el while vuelve a preguntar. Si la conversión funciona, el return dentro del try se ejecuta de inmediato y corta el bucle devolviendo el valor — nunca se llega al except cuando no hay error.

10. POO: clase Agente y subclase AgenteEspecial

class Agente:
    nivel = 'Regular'                       # atributo de clase

    def __init__(self, nombre_real, edad, nombre_clave):
        self.nombre_real = nombre_real      # atributos de instancia
        self.edad = edad
        self.nombre_clave = nombre_clave

    def __str__(self):
        return f'Agente {self.nombre_clave}.'

    def reporte(self):
        return f'Mi nombre real es {self.nombre_real}, tengo {self.edad} años.'


class AgenteEspecial(Agente):               # hereda de Agente
    nivel = 'Especial'

    def __init__(self, nombre_real, edad, nombre_clave, mision, pais):
        Agente.__init__(self, nombre_real, edad, nombre_clave)
        self.mision = mision
        self.pais = pais

    def reporte(self):                      # sobre-escribe el método del padre
        print(f"Puede llamarme {self.nombre_clave}")

    def _mision(self):
        return f'Misión actual: {self.mision}'


b = Agente('Beto', 50, 'Caribú')
print(b)             # Agente Caribú.  (usa __str__)
print(b.nivel)        # Regular

n = AgenteEspecial('Norma', 40, 'Nana', 'Keto', 'USA')
print(n)             # Agente Nana.  (__str__ heredado, sin redefinir)
n.reporte()          # Puede llamarme Nana  (versión sobre-escrita)

AgenteEspecial(Agente) hereda todo de Agente y llama a Agente.__init__(self, ...) para no perder la inicialización de los tres primeros atributos, antes de agregar mision y pais propios.

nivel es un atributo de clase: cada clase define su propio valor ('Regular' vs. 'Especial'), compartido por todas sus instancias. reporte() se sobre-escribe en la subclase (mismo nombre, comportamiento distinto); en cambio __str__ no se redefine, así que n usa la versión heredada de Agente. _mision con un guion bajo es una convención de método "privado", solo pensado para usarse dentro de la clase.

Fuente: ayudantía de POO (clase Agente / AgenteEspecial).

13. Escribe una función division_segura(a, b) que retorne a / b, y si b es 0, capture el error y retorne None en vez de que el programa se caiga. fácil 
def division_segura(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return None

print(division_segura(10, 2))    # 5.0
print(division_segura(10, 0))    # None

try intenta la división; si b es 0, Python lanza ZeroDivisionError y el except lo captura, retornando None en vez de que el programa termine con un traceback. Cuando b no es 0, el return a / b del try se ejecuta sin problema y el except nunca se alcanza.
